# Kairos v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Kairos v1, a single-container, single-user web dashboard. For any US stock/ETF it produces a sourced "reading" (lean, drivers, bull/bear case) alongside metrics computed in code (price context, events, hype flags, quick numbers), with a track record and Discover suggestions.

**Architecture:** A Python FastAPI backend gathers data through independent source adapters (yfinance, Finnhub, Google News RSS, SEC EDGAR, optional Reddit RSS) and computes every number in code. It makes one budgeted Gemini call per ticker for the qualitative summary, validates that call against supplied source IDs, and stores readings in SQLite. A React + Vite + TypeScript frontend (layout A: sidebar plus reading panel) is built into static files that FastAPI serves. An in-process APScheduler runs the morning refresh, outcome filling and Discover.

**Tech Stack:** Python 3.14 (uv, FastAPI, uvicorn, httpx, feedparser, yfinance, pandas, google-genai, pydantic-settings, APScheduler, pytest, respx, ruff); Node 24 LTS (Vite, React, TypeScript, TanStack Query, axios, Zod, Zustand, lightweight-charts, Vitest, Testing Library); SQLite via stdlib `sqlite3`; Docker multi-stage + Compose.

**Spec:** `docs/superpowers/specs/2026-11-02-kairos-design.md`. Read it before starting any task.

## Global Constraints

- Free tiers only; no paid API required to run. Gemini model ID comes from env `GEMINI_MODEL` (default `gemini-flash-latest`).
- No LLM-generated numbers: prices, averages, valuation figures and hype signals are computed in code.
- Every AI claim cites supplied source IDs. Claims citing unknown IDs are dropped. Thin evidence → `not_enough_signal`, with no Gemini call.
- The owner's holdings/quantities are never included in any Gemini prompt.
- Gemini budget defaults: `GEMINI_RPM=10`, `GEMINI_RPD=200`. On HTTP 429 → `ai_status="budget_exhausted"`, computed sections still returned.
- Reading cache: `READING_CACHE_HOURS=4`. Morning refresh: `MORNING_REFRESH_TIME=07:00` in `TZ`.
- Reddit add-on off by default (`REDDIT_ENABLED=false`). The app must work fully without Reddit and without Finnhub (degraded, shown in data health).
- Hype thresholds (env-configurable): micro-cap `< 300_000_000` USD; price spike `> 30%` over 5 trading days; penny `price < 5`; low volume `30-day avg volume < 100_000`; attention spike `>= 3x` baseline with `>= 5` recent articles.
- Track record horizons: `+1, +5, +20` trading days; baseline is VOO over the same window; only the first reading per (ticker, calendar day) counts.
- Open source: `.env`, `data/`, `node_modules/`, `dist/`, `.venv/`, `__pycache__/` are gitignored; gitleaks pre-commit hook; `KAIROS_SEED_HOLDINGS` and `KAIROS_SEED_WATCHING` (comma-separated, default empty) seed lists on first DB init; MIT license; README carries "research tool, not financial advice".
- Bind to `127.0.0.1:8000` in Compose. API keys stay server-side; `/api/settings` exposes only booleans for whether keys are configured.
- Versions: latest stable libraries, LTS runtimes, no day-one majors. Commit `uv.lock` and `package-lock.json`. Conventional commit messages (`feat:`, `fix:`, `docs:`, `chore:`, `test:`). Work on branch `feat/v1`.

## Review Focus

1. **Odd ticker input in the search bar** (`nvda`, ` $NVDA `, `BRK.B`, `XYZQQ`, empty): normalize to Yahoo form; an unknown ticker returns 404 `{"detail": "Unknown ticker: XYZQQ"}` and the UI shows that message. No 500, no empty reading. Tests in Task 2 (normalize) and Task 8 (404).
2. **Gemini key missing/invalid or quota hit:** the reading still renders price, events, hype and numbers, with `ai_status` = `not_configured` / `unavailable` / `budget_exhausted`. Tests in Task 7 and Task 8; UI state in Task 13.
3. **Very little news** (obscure ticker, weekend): fewer than 3 cleaned items → `ai_status="not_enough_signal"`, Gemini not called, budget untouched. Test in Task 8.
4. **Short price history** (recent IPO < 200 sessions, < 50 sessions) and **non-trading days**: MA200 is `None` without crashing; < 50 closes → label `insufficient_history`. Tests in Task 3.
5. **Finnhub key missing, or an ETF where yfinance returns no holdings:** news falls back to Google RSS (ETF: falls back to the ETF ticker's own news); data health shows `not_configured`/`error` for the failed source. Tests in Task 4 and Task 8.

### Shared models (`backend/kairos/models.py`). Every task uses these names.

```python
SourceName = Literal["yfinance", "finnhub", "google_news", "sec", "reddit", "gemini"]
class SourceStatus(BaseModel): name: SourceName; status: Literal["ok","error","disabled","not_configured"]; detail: str | None = None
class AdapterResult(BaseModel, Generic[T]): items: list[T]; status: SourceStatus
class NewsItem(BaseModel): id: str; source: SourceName; title: str; summary: str; url: str; published_at: datetime; related_ticker: str; weight: float = 1.0
    # id = first 10 hex chars of sha1(url)
class PricePoint(BaseModel): date: date; close: float
class PriceContext(BaseModel): last_price: float; day_change_pct: float | None; ma50: float | None; ma200: float | None
    pct_vs_ma50: float | None; pct_vs_ma200: float | None; high_52w: float; low_52w: float; pct_from_52w_high: float
    volatility_30d: float | None   # annualized stdev of daily returns, percent
    label: Literal["stretched","near_average","below_range","insufficient_history"]; history: list[PricePoint]
class MacroEvent(BaseModel): date: date; kind: Literal["FOMC","CPI"]
class Events(BaseModel): next_earnings: date | None; earnings_within_7d: bool; next_ex_dividend: date | None; macro: list[MacroEvent]
class Holding(BaseModel): symbol: str; name: str; weight: float   # weight as fraction 0..1
class QuickNumbers(BaseModel): kind: Literal["stock","etf"]
    market_cap: float | None = None; trailing_pe: float | None = None; forward_pe: float | None = None
    sector: str | None = None; sector_pe: float | None = None; revenue_growth: float | None = None; profit_margin: float | None = None
    expense_ratio: float | None = None; aum: float | None = None; top_holdings: list[Holding] = []
class HypeFlag(BaseModel): code: Literal["attention_spike_no_substance","micro_cap","price_spike","otc","penny","low_volume"]; triggered: bool; value: str
class Reading(BaseModel): ticker: str; name: str; kind: Literal["stock","etf"]; created_at: datetime
    price: PriceContext | None; events: Events; quick: QuickNumbers; hype: list[HypeFlag]
    ai: AISummary | None; ai_status: Literal["ok","not_enough_signal","budget_exhausted","unavailable","not_configured"]
    sources: list[NewsItem]; data_health: list[SourceStatus]
```
